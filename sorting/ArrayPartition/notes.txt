Array Partition
Given an integer array nums of 2n integers, group these integers into n pairs (a1, b1), (a2, b2), ..., (an, bn) such that the sum of min(ai, bi) for all i is maximized. Return the maximized sum.

Input: [1,4,3,2] Output:4
Explanation:
All possible pairings (ignoring order) are (1,4) and (3,2), min values are 1 and 2, sum is 3; or (1,3) and (4,2), min values are 1 and 2, sum is 3; or (1,2) and (3,4), min values are 1 and 3, sum is 4 which is maximum.

Array Partition – Maximize Sum of Minimums (Concept Notes)

To maximize the sum of minimums of pairs, sort the array in ascending order.
After sorting, pair adjacent elements together, because this minimizes the loss between numbers in each pair.
In each sorted pair, the first element is always the minimum, so add elements at even indices to the sum.
Pairing large numbers together prevents wasting a large number as the minimum of a pair.
This greedy strategy guarantees the maximum possible sum.

Sort → pair neighbors → sum every first element.

nums = [1, 4, 3, 2] sort => [1, 2, 3, 4] max the sum of min is (1, 2) → min = 1 (3, 4) → min = 3 sum =4
alternate element is          1     3    sum = 1+3=4 easy
you can try out all possible but max sum if min is 4
