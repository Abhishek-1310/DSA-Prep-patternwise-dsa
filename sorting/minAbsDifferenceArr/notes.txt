While traversing the array, we calculate differences between adjacent elements and track the minimum difference.
Since we don’t know the minimum in advance, we compare each difference with the current min.
If a smaller difference is found, previous pairs become invalid, so we reset the result array with the new pair.
If the difference equals the current minimum, we add the pair to the result.
This prevents keeping pairs with larger differences that would otherwise produce incorrect output.
